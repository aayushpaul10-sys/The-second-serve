# The Second Serve website

Static HTML/CSS/JS website for The Second Serve.

## Upload to GitHub Pages
Upload the contents of this folder to the root of your GitHub repository. Keep the `assets` folder and everything inside it together.

Expected structure:

```text
index.html
about.html
partner.html
sponsors.html
founders.html
donate.html
styles.css
script.js
assets/
  logo.png
  aayush-paul.png
  ryan-fan.jpg
```

The site uses only relative paths, so it works with a custom domain on GitHub Pages.

## Important
The logo and founder photos have been converted to standard browser-safe PNG/JPEG files. If you manually upload files to GitHub, make sure the filenames and capitalization match the HTML exactly.

The header uses the same official logo image on every page for consistency.
